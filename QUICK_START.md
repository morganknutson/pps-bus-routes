# Quick Start

## Option 1: Double-Click (macOS)
1. Double-click `start.command` in this folder
2. The app will open in your browser at http://localhost:3000

## Option 2: Terminal Command
```bash
npm start
```

Or:
```bash
npm run dev
```

## Option 3: Run Script
```bash
./start.sh
```

## First Time Setup
On first run, the app will automatically install all dependencies. This may take a minute.

## What Happens
- Backend server starts on port 3001
- Frontend server starts on port 3000
- Browser should open automatically (or go to http://localhost:3000)

## To Stop
Press `Ctrl+C` in the terminal window
